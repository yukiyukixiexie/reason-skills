# reason-skills

A collection of Claude Code skills for career coaching and professional development.

## Skills

| Skill | Trigger | Description |
|-------|---------|-------------|
| resume-analyzer | `/resume` | 简历分析与修改建议 |
| interview-prep | `/interview` | 面试准备与题库生成 |
| offer-compare | `/offer` | Offer 对比与谈判建议 |
| career-plan | `/career` | 职业规划与成长路线图 |

## Usage

Install a skill by copying the skill folder into your `.claude/skills/` directory.
